# LinkDesk 배포 안내

전문형 북마크 디렉터리로 정리한 GitHub Pages용 소스입니다. 별도 프레임워크나 설치 과정 없이 `index.html`, `styles.css`, `script.js`만으로 동작합니다.

## 반영 순서

1. `북마크_프로페셔널_정리본.xlsx`의 `시트1`을 현재 Google Sheets에 가져옵니다.
2. 첫 행의 `순서 / 카테고리 / 사이트명 / URL / 아이콘` 구조와 시트 이름 `시트1`을 유지합니다.
3. 이 폴더의 `index.html`, `styles.css`, `script.js`를 GitHub 저장소의 기존 파일과 교체합니다.
4. GitHub Pages 배포가 끝나면 브라우저에서 강력 새로고침합니다.

`정리 내역` 시트는 검증 보고서이므로 웹 API 데이터 범위에는 포함하지 않아도 됩니다.

## 이번 정리 결과

- 최종 링크: 929개
- 카테고리: 102개
- 중복 제외: 109개
- 대체 주소가 없는 확정 죽은 링크 제외: 27개
- 공식 주소 교체: 21개
- HTTPS 전환: 21개
- 신규 추가: Microsoft Copilot, Google Calendar, VirusTotal URL 검사

자동 확인이 차단되거나 결과가 불확실한 링크는 삭제하지 않고 엑셀의 `정리 내역` 시트에 검토 대상으로 남겼습니다.
